## 1. Context & Problem Statement

Evaluating autonomous multi-agent systems presents a fundamental scoring dilemma:
1. **The Inadequacy of Pure Heuristics**:
   - Rigid lexical metrics (BLEU, ROUGE) and regex assertions fail completely on natural language customer dialogue. A correct, highly empathetic technical explanation phrased differently from a reference response scores near zero on n-gram overlap.
2. **The LLM-as-a-Judge Self-Enhancement Trap ($UU3$, `EV-Q3`)**:
   - Utilizing large language models as judges introduces severe cognitive biases (Zheng et al., 2023):
     - **Self-Preference Bias**: Models systematically score responses generated by their own family higher than responses from competing architectures ($\mathbb{E}[S(M_A \mid \text{Judge}_A)] > \mathbb{E}[S(M_B \mid \text{Judge}_A)]$).
     - **Verbosity Bias**: Judges favor longer, overly verbose responses over concise, precise answers.
     - **Position Bias**: In pairwise comparisons, judges disproportionately favor the first candidate presented.
3. **The Uncalibrated Confidence Cliff (`ADP-05-Q2`)**:
   - Modern neural networks and LLMs are notoriously uncalibrated: when an internal routing classifier or Jev decision model outputs a confidence score of $0.90$, its empirical real-world accuracy may be only $0.68$.
   - Using uncalibrated raw softmax probabilities or naive confidence numbers to gate financial operations ($>\$1,000$, `TA-D5`) or safety escalations leads to catastrophic under-escalation of critical errors.

### The Core Architectural Question
> **How do we construct an objective, reproducible scoring engine that combines deterministic state assertions with an unbiased cross-family LLM judge, and how do we systematically calibrate decision thresholds per route prior to every production release?**

### Pillar 1: Hybrid Scoring Engine & Cross-Family Neutrality (`EV-D2`)

We enforce a strict division between deterministic verification and open-ended semantic scoring:

#### Tier 1: Deterministic State Assertions
Where physical ground truth exists, LLM judges are strictly bypassed. Assertions evaluate:
1. **Tool Invocation State**: Did the agent call `issue_refund` with `amount = 45.00` and `reason = "SERVICE_OUTAGE"`?
2. **Policy Compliance**: Did the agent route to human approval before calling financial tools with values $\ge \$1,000$ (`TA-D5`)?
3. **Information Leakage**: Does the output contain prompt delimiters, system prompt verbatim text, or unmasked PII tokens (`SG-D6`)?

#### Tier 2: Cross-Family LLM Judge Formulation (`EV-Q3`)
For open-ended qualities (faithfulness to retrieved context, tone de-escalation, explanation clarity), we utilize a calibrated LLM judge.
To mathematically eliminate the **Self-Enhancement Bias** ($\Delta_{\text{self}}$):
$$\Delta_{\text{self}} = \mathbb{E}\left[ S(M_A \mid \text{Judge}_A) \right] - \mathbb{E}\left[ S(M_A \mid \text{Judge}_B) \right] > 0$$
We mandate that:
$$\text{Family}(\text{Judge}) \cap \text{Family}(\text{Agent Runtime}) = \emptyset$$
- If the agent runtime utilizes Anthropic Claude models (e.g., Claude 3.5 Sonnet), the evaluation judge must be OpenAI GPT-4o.
- If the agent runtime utilizes OpenAI GPT-4o, the evaluation judge must be Anthropic Claude 3.5 Sonnet.

#### Human Alignment via Cohen's Kappa ($\kappa$)
Before an LLM judge rubric is accepted for automated scoring, it must achieve inter-annotator agreement of $\kappa \ge 0.80$ against a gold validation set of 200 human-annotated conversations:
$$\kappa = \frac{p_o - p_e}{1 - p_e} \ge 0.80$$
where $p_o$ is observed agreement and $p_e$ is hypothetical chance agreement.

### Pillar 2: Pre-Release Empirical Route Calibration (`EV-D9`)

Raw confidence logits emitted by decision models (Jev triage `ADP-05`, screening classifiers `SG-D2`, and specialist routers `MA-D3`) are uncalibrated. Prior to every production release, threshold calibration runs against hold-out validation sets.

#### 1. Expected Calibration Error (ECE)
The validation predictions are partitioned into $M = 10$ equally spaced confidence bins $B_1, B_2, \dots, B_M$. The Expected Calibration Error is defined as:
$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$
where:
$$\text{conf}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} \hat{p}_i, \quad \text{acc}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} \mathbf{1}(y_i = \hat{y}_i)$$

#### 2. Temperature Scaling Optimization
For each decision route $r$, an optimal scalar temperature $T_r > 0$ is learned on the validation logits $z$ by minimizing cross-entropy (Negative Log-Likelihood):
$$T_r^* = \arg\min_{T > 0} -\sum_{i=1}^{N_r} \sum_{k=1}^{K} y_{i,k} \log \left( \frac{\exp(z_{i,k} / T)}{\sum_{j=1}^{K} \exp(z_{i,j} / T)} \right)$$
Calibrated probability is then computed as:
$$\hat{p}_{i,k}^{\text{calibrated}} = \frac{\exp(z_{i,k} / T_r^*)}{\sum_{j} \exp(z_{i,j} / T_r^*)}$$

#### 3. Threshold Setting by Target Precision
The operational confidence threshold $\tau_r$ for route $r$ is derived to guarantee target precision (e.g., $99.5\%$ for financial operations, $95.0\%$ for technical triage):
$$\tau_r = \min \left\{ \theta \in [0, 1] \;\middle|\; \mathbb{P}\left( \text{Correct} \;\middle|\; \hat{p}^{\text{calibrated}} \ge \theta \right) \ge \text{TargetPrecision}_r \right\}$$

#### 4. Fallback for Rare Routes ($KU3$)
If a decision route has fewer than $N_{\text{min}} = 100$ historical validation instances, temperature scaling is statistically unreliable. The framework automatically falls back to the **Conservative Default Floor** ($\tau_{\text{fallback}} = 0.95$), forcing human co-pilot review for low-volume routes until sufficient samples accumulate.

### 3.2 Cross-Family Neutrality Invariant

$$\forall \text{ Run } R, \quad \text{ModelVendor}(R.\text{agent\_model}) \neq \text{ModelVendor}(R.\text{judge\_model})$$
If an agent build running `claude-3-5-sonnet` is evaluated, the CI harness rejects any configuration specifying `claude-3-opus` or `claude-3-haiku` as the judge model.

## 6. Genesis Implementation Directive & Verification Protocol

### 6.1 Temperature Scaling Calibration Optimizer Implementation

```python
import numpy as np
from scipy.optimize import minimize
from pydantic import BaseModel

class RouteCalibrator:
    def __init__(self, route_name: str, min_sample_size: int = 100):
        self.route_name = route_name
        self.min_sample_size = min_sample_size

    def calibrate(self, logits: np.ndarray, labels: np.ndarray, target_precision: float = 0.99) -> dict:
        """
        Learns optimal temperature scalar T* via NLL loss and computes target threshold.
        """
        num_samples = len(labels)
        if num_samples < self.min_sample_size:
            # Fall back to high-security conservative default (EV-D9, KU3)
            return {
                "route_name": self.route_name,
                "temperature": 1.0,
                "calibrated_threshold": 0.95,
                "is_fallback": True,
                "sample_size": num_samples
            }

        # Loss function: Negative Log-Likelihood over validation set
        def nll_objective(t):
            temp = t[0]
            scaled_logits = logits / temp
            # Stable log-softmax
            exp_logits = np.exp(scaled_logits - np.max(scaled_logits, axis=1, keepdims=True))
            probs = exp_logits / np.sum(exp_logits, axis=1, keepdims=True)
            loss = -np.mean(np.log(probs[np.arange(num_samples), labels] + 1e-12))
            return loss

        res = minimize(nll_objective, x0=[1.0], bounds=[(0.1, 5.0)], method="L-BFGS-B")
        opt_temp = float(res.x[0])

        # Compute calibrated probabilities
        scaled_logits = logits / opt_temp
        exp_logits = np.exp(scaled_logits - np.max(scaled_logits, axis=1, keepdims=True))
        calibrated_probs = exp_logits / np.sum(exp_logits, axis=1, keepdims=True)
        max_probs = np.max(calibrated_probs, axis=1)
        correct_predictions = (np.argmax(calibrated_probs, axis=1) == labels)

        # Search for threshold satisfying target precision
        thresholds = np.linspace(0.5, 0.99, 100)
        chosen_threshold = 0.95
        for th in thresholds:
            mask = max_probs >= th
            if np.sum(mask) > 0:
                precision = np.mean(correct_predictions[mask])
                if precision >= target_precision:
                    chosen_threshold = float(th)
                    break

        return {
            "route_name": self.route_name,
            "temperature": opt_temp,
            "calibrated_threshold": chosen_threshold,
            "is_fallback": False,
            "sample_size": num_samples
        }
```

## 7. Trade-Off Analysis & Rejected Alternatives

| Dimension | Selected Paradigm (`EV-D2`, `EV-D9`) | Rejected Alternative A: Deterministic Assertions Only | Rejected Alternative B: Jev as Universal Evaluator |
| :--- | :--- | :--- | :--- |
| **Semantic Quality Coverage** | **High**: Evaluates tone, conversational coherence, empathy, and contextual nuance via calibrated judge. | **Zero**: Misses qualitative failures; cannot distinguish a polite explanation from a rude or robotic brush-off. | **Moderate**: High coverage, but prone to instruction drift and circular evaluation artifacts. |
| **Neutrality & Self-Preference** | **Guaranteed**: Cross-family mandate completely eliminates self-enhancement bias ($UU3$, `EV-Q3`). | **Absolute**: Pure code assertions possess zero model bias. | **Compromised**: Evaluating Jev models using Jev creates a self-fulfilling validation loop. |
| **Statistical Reliability** | **High**: Temperature scaling mathematically minimizes ECE; threshold mapped directly to target precision. | **High**: Hard binary pass/fail criteria. | **Low**: Raw uncalibrated probabilities treated as true probabilities, risking under-escalation. |
| **Execution Cost & Latency** | **Optimized**: Two-tier design filters failures via free assertions before spending tokens on judge LLM. | **Lowest**: Microsecond execution in local Python runtime. | **High**: Incurs LLM API billing on every single test turn regardless of invariant failures. |
