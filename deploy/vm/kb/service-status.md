# Checking service status

Our status page shows the health of every component (web app, API, sign-in, billing) and any incident in
progress, with updates as we work on it. If something is not working, check the status page first: if an
incident is listed, there is no need to report it again, and the page tells you when it is resolved.

If the status page shows everything operational but you still see errors, tell us the time it happened, the
page or API endpoint, and any error code you saw.
